# Muinsight
An AI-powered music companion designed to make Apple Music listening more understandable and immersive.

## Overview

Muinsight connects with a user's Apple Music library and enhances the listening experience with lyric translation and AI-powered song interpretation.

The project explores how AI can add context and meaning to everyday music consumption without interrupting the native listening experience.

## Key Features

- Apple Music library integration
- Album and playlist browsing
- Real-time lyric display
- Chinese lyric translation
- AI-generated explanations of lyrics, themes, and cultural references
- Native iOS interface built around the Apple Music experience

## Product Motivation

Music listeners often encounter lyrics, cultural references, or expressions they do not fully understand.

Muinsight aims to reduce this gap by combining music playback, translation, and AI interpretation in one lightweight experience.

## Tech Stack

- Swift
- SwiftUI
- MusicKit
- Apple Music API
- AI API integration
